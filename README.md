# iot-car-parking-gate
a test (learning phase) project for iot sensors using multiple sensors to automatically open and close parking gate with the coming of vehicle

Components:
- ESP32
- IR Sensor
- OLED Display  
- Servo Motor
- ESP 32

Note: learnt about individual sensor from  ISA training
